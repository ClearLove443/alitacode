# ALITA-METHOD Agents and Tasks (OpenCode)

OpenCode reads AGENTS.md during initialization and uses it as part of its system prompt for the session. This section is auto-generated by ALITA-METHOD for OpenCode.

## How To Use With OpenCode

- Run `opencode` in this project. OpenCode will read `AGENTS.md` and your OpenCode config (opencode.json[c]).
- Reference a role naturally, e.g., "As dev, implement ..." or use commands defined in your ALITA tasks.
- Commit `.alita-core` and `AGENTS.md` if you want teammates to share the same configuration.
- Refresh this section after ALITA updates: `npx alita-method install -f -i opencode`.

### Helpful Commands

- List agents: `npx alita-method list:agents`
- Reinstall ALITA core and regenerate this section: `npx alita-method install -f -i opencode`
- Validate configuration: `npx alita-method validate`

Note
- Orchestrators run as mode: primary; other agents as all.
- All agents have tools enabled: write, edit, bash.
